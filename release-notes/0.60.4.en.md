Nota 0.60.4 puts sidechain pumping back on the kick in the exported file, runs on macOS 12 and installs on NixOS.

<!-- changes -->
**Added**
• Nota on NixOS: `nix run github:nota-daw/nota` builds Nota from its flake and starts it (x86_64 and aarch64 Linux), with every dependency pinned so the build needs no network. In a checkout, `nix develop` or `devenv shell` opens a shell with the build tools ([2ef6fce](https://github.com/nota-daw/nota/commit/2ef6fced6c8ec2bd2e8a60314e35a26a09898c15), [68669d1](https://github.com/nota-daw/nota/commit/68669d1c85632e909c890dd963615d7bdbd68799), [5b3ed1b](https://github.com/nota-daw/nota/commit/5b3ed1b121f7b7110d80b8b894d1f31336e540cd))

**Changed**
• Nota runs on macOS 12 (Monterey) and later; it used to need macOS 13 ([1f52aa5](https://github.com/nota-daw/nota/commit/1f52aa5b7cf915c2aa18395ea7d7b4c8628dc5de))

**Fixed**
• A device keyed by another track — a Compressor ducking under the kick, a gate, Dynamic EQ, the vocoder, Nota Flux's React — hears its key track in the same moment, live and in the export. It used to hear the key one audio block late: a few milliseconds while you worked, but a whole export chunk (about 170 ms) in the exported file, so the pumping landed well after the kick. Live, keyed devices react without the buffer's delay too ([3a71863](https://github.com/nota-daw/nota/commit/3a71863936c0e3f415cbe7aaf4aacd0eba8b37f1))
