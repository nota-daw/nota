# Nota design language — Ember

Warm neutrals (hue ~40°) lit by exactly one accent, **brass**, in two variants:
**Ember Graphite** (dark, the default) and **Ember Paper** (light — same roles, brass
darkened to bronze). Preferences → Appearance picks Graphite / Paper / System; the switch
is live. The rules come from the **Nota Design Almanac** (`nota-design/Nota.html`, beside
the mockups); `DESIGN.md` is that almanac as the app implements it, plus the departures
the project accepted.

## Read these first — do not work from memory

| File | What it gives you |
|---|---|
| `DESIGN.md` | **The guideline.** Rules, every token value for both variants, type scales, number setting, controls and states, device cards, shell, the tests, accepted departures, known drift. Start here. |
| `DESIGN.html` | The same thing rendered — swatches, control specimens, a device card at true size, Graphite/Paper toggle. Generated by `scripts/design-html.py`. |
| `src/managed/Nota.App/Theme/NotaTheme.axaml` | **Definitive** colour (Dark + Light), geometry, type classes, control styles. |
| `Theme/NotaPalette.cs` | Colour slots for custom-drawn views (`Wash`, `Ink`, `Derived`). |
| `Theme/NotaGeometry.cs` · `NotaFonts.cs` · `NotaNum.cs` | Radii/sizes/spacing · Geist typefaces and type scale · number formatting. |
| `DeviceCardKit.cs`, `Controls/` | The shared controls and card builders; `Controls/NotaGraph.cs` for graph windows. |
| `tests/Nota.SmokeTest/DesignTokenCheck.cs` | The guard tests — run the smoke test after any UI change. |

If `DESIGN.md` / `DESIGN.html` disagree with the theme files, **the theme files win** and
the docs need fixing. Say so rather than propagating the drift.

> This skill deliberately does **not** restate token values. An earlier version did, and
> it drifted a whole palette out of date. Read the files.

## Non-negotiables

Most of these are enforced by `DesignTokenCheck`; the smoke test fails when one breaks.

- **No literals in views.** XAML: `{DynamicResource Brush.*}` (a `StaticResource` cannot
  follow the variant) and `{StaticResource Radius.*|Control.*|Space.*}`. C#: `NotaPalette`
  (a slot, `Wash(slot, alpha)`, `Ink("#hex")` for a one-off device hue), `NotaRadius`,
  `NotaSize`, `NotaSpace`, `NotaFonts`, `NotaType`. No hex outside `Ink()`, no RGB typed as
  numbers, no `Colors.X` / `Brushes.X` except `Transparent`, no font family names.
- **Nothing may snapshot a colour.** `new SolidColorBrush(slot.Color)`, a
  `static readonly Color` or brush built from the palette, or a static array of palette
  colours freezes the view in one variant. Use the slot, `Wash`, `Derived`, a property, or
  read `.Color` inside `Render`. Track colours: `ArrangementView.TrackBrush(index)`.
- **One accent.** Brass means active, selected, changed. Red is recording and overload
  only; green and yellow are meter zones and live signal. There is no second accent.
- **Role chromas (brass · teal · rose · steel) live only inside graphs**, in that order,
  never on buttons or as state. A modulated knob's arc takes its source's chroma.
- **Flat, three levels deep.** No gradients, glow, textures or drop shadows (only a
  floating plugin window has one). Depth is lightness + hairline + an inner top line.
- **Opacity is not a state.** Disabled and muted take the next Ink step; use
  `Inactive.Set` for a subtree. The only allowed `Opacity` is a drag ghost.
- **State changes colour only** — never size, border width or position. Hover and colour
  transitions 120 ms ease-out; meters, playhead and spectra are never animated.
- **Geist for words, Geist Mono for measurements.** Nothing under 7 px.
- **Numbers are set, not printed.** The app installs a display culture (point decimal,
  U+2212 minus). Put a thin space ` ` before units, keep precision fixed (dB one
  decimal, tempo two, percent whole, Hz up to 999 then `3.2 k`) — use `NotaNum` helpers.
- **Icons are geometry.** `Glyph` / `GlyphKind`; no unicode symbols (`■ ▶ ● ✓ ★ ▾`…) and
  no emoji as text. `·` separates meta; `→` in prose is fine.
- **Copy:** English. Parameter labels caps, one word, no vowel-dropped contractions
  (`FEEDBACK`, not `FDBK`; `FREQ`/`RESO`/`THRESH` are allowed). Tooltips short and
  verb-first. Sentence case. Empty states are one Ink 5 line.

## Device cards

- **700 × 260** (`DeviceCardKit.CardH`; width exceptions are listed in `DESIGN.md`).
- **Header 22:** name left; processing-type badge (mono caps) and bypass right — nothing
  else. Presets, A/B, move, delete go in the header's right-click menu.
- **Body:** inset 6, sections radius 6 with gap 5; columns choice → work → output.
- Brass for the audio path and active state; modulation shows its source chroma; graphs go
  through `NotaGraph` (Well, hairline, radius 4, corner axis labels, no fills under curves).

## Adding a control

Reuse before writing: `Knob` (sizes snap to 34/36/44), `DeviceCardKit.KnobCell` (53 tall),
`SwitchTrack` / `DeviceCardKit.Switch` (18 × 10), `DeviceCardKit.Segments`, `SliderTrack` /
`DeviceCardKit.SliderRow`, `MiniFader`, `PanBar`, `VFader`, `DragNumber`, `MeterBar` /
`StereoMeter` / `GrMeter`, `Glyph`, `NaBadge`. Sizes and specs: `DESIGN.md` § Controls.

A new value control **must** match the interaction contract:

- Vertical drag, up increases, full range over ~140 px; Shift/Ctrl/⌘ for fine steps;
  `ns-resize`; a click never jumps the value; no horizontal drag
- Double-click restores the default
- Left button only — right-click must bubble to the CV-modulate / MIDI Learn menu
- `GestureBegin` / `GestureEnd` bracket `BeginAutomationWrite` / `EndAutomationWrite`
- Register with `MidiLearn.Bind`
- Live-follow refresher that **skips while dragging**
- Mono readout so width does not jump; the value is always visible, not only in a tooltip

## Applying it (Avalonia)

- `NotaTheme.axaml` is merged in `App.axaml`; `NotaThemeService` applies the variant to both
  layers. `NotaNum.Install()` runs in `App.Initialize`.
- Buttons: default (raised), `primary` (one solid brass action per context), `ghost`,
  `cell`, `chip`, `tp-icon`, `tp-play`; `ToggleButton.seg` inside `Border.segmented`.
  Containers: `Border.Panel`, `Border.Card`, `Border.well`, `Border.transport`,
  `Border.console`. Fields: `TextBox.field`, `TextBox.search`.
- Text: shell `Title`, `Heading`, `Name`, `Caption`, `SectionLabel`, `Readout`, `Value`,
  `Eyebrow`; device `DeviceName`, `DeviceSection`, `RowLabel`, `KnobLabel`, `KnobValue`,
  `Axis`.

## When you change a token

1. Edit **both** branches in `NotaTheme.axaml` — `Dark` and `Light`.
2. Mirror the pair into the `NotaPalette` slot — the smoke test checks the pair.
3. Run `python3 scripts/design-html.py` and update the table in `DESIGN.md`.
4. Check both variants — in the app and in `DESIGN.html` (`?variant=paper`).
