# Quickstart & Verification Guide: Polyphonic Synth FastMath & SIMD Buffer Inspection

**Feature**: `027-dsp-synth-vector-optimizations`
**Date**: 2026-10-17

## Overview

This guide details how to verify the correctness, numerical stability, and performance improvements of Feature 027 using the automated test suite and benchmarks.

---

## 1. Prerequisites & Environment

- **Build Script**: `./scripts/build.sh` (macOS), `./scripts/build-linux.sh` (Linux), or `./scripts/build-win.ps1` (Windows).
- **Compilers**: Clang 17+ / GCC 13+ / MSVC 2022 with C++20 and ARM NEON / SSE2 / AVX2 flags enabled.
- **Test Runner**: .NET 10 SDK (`dotnet run --project tests/Nota.SmokeTest`).

---

## 2. Test Scenarios

### Scenario A: SIMD Buffer Inspection Correctness
Verify that `simd::isSilent` and `simd::peakAndSumSquares` yield identical results to scalar references across all boundary cases:
1. All zeros (silence).
2. Sub-threshold noise ($< 1.0\times 10^{-5}$).
3. Single isolated impulse at index 0, 7, 15, and 31.
4. Active full-scale sinusoid.
5. Buffer sizes not divisible by 16 (verifying tail cleanup loops).

### Scenario B: Polyphonic Synthesis Audio Fidelity
Verify that audio output generated by `OperatorSynth`, `WavetableSynth`, `PendulumSynth`, `VoltSynth`, `FluxSynth`, and `BassSynth` remains within perceptual tolerance:
- Maximum sample-level error $< 0.05\text{ dB}$.
- Harmonic distortion spur suppression $> 65\text{ dBFS}$.
- No DC offsets or NaN/Inf corruption under rapid pitch-bend and high FM modulation index.

### Scenario C: Performance Benchmarking
Measure CPU execution time across 1000 blocks ($N=256$ frames):
1. **Silence detection**: Benchmark `isBufferSilent` on 64 tracks of silence vs active audio.
2. **Polyphonic synthesis**: Benchmark 8-voice chord playback in `OperatorSynth` (FM mode) and `PendulumSynth` (harmonic mode).

---

## 3. Execution Commands

```bash
# 1. Clean build native engine and run all smoke tests
./scripts/build.sh

# 2. Targeted run of DSP optimization smoke test
dotnet test tests/Nota.SmokeTest --filter "Category=DspOptimization"
```

Expected result:
```text
SMOKE TEST PASSED
All tests passed without errors or assertions.
```
