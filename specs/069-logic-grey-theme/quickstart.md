# Validation quickstart

1. Build with pwsh scripts/build-win.ps1 in the existing x64 Visual Studio environment.
2. Launch Release; select Settings -> Appearance -> Dark -> Logic Grey.
3. Confirm Arrangement, piano roll/CC, mixer and dialogs repaint; data hues/layout stay fixed.
4. Restart: Logic Grey returns. Select Studio Dark: original colours return.
5. Check Follow system remembers Logic Grey only for its dark choice.
6. Inspect/capture 100%, 125%, 150%, 200% scaling.
7. Compare playback frame cadence and dropout count for Studio Dark and Logic Grey.
Record commands, screenshots, checks and limitations in validation.md.
