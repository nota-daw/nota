Sends in the arrangement track headers (specs/072, nota-daw/nota#143)

Studio Dark, 1 : 1. The send row is new; everything else is today's header. One inline knob (24) per return in bus order, each with its bus letter over a mono percent read-out. Arcs rest in VizInk; the accent appears only on the knob under the pointer or in the hand (bus A below is being dragged). The Sends toggle sits at the right end of the header column's top strip; on = the solid accent key.

  • Standard row, ≥ 88 px: name · routing + M/S/● · volume|pan (2 : 1) · sends. Below 88 px the standard header is unchanged.
  • Large row: with sends shown, volume and pan share one row (as on a standard row) so the send row fits the 128 px preset; with sends hidden the large layout is unchanged (pan on its own row).
  • Narrow column: when a cell can't hold knob + letter/value, the cells drop to knobs only; the letter, return name and value move to the tooltip and the ⌥-click value box.
  • Tooltip: "Send A · Reverb · 42 %". Double-click resets to 0 %. Compact rows, return / master footer rows and the slim group bar get no send row.
  • No returns → no send row and no Sends toggle.
