## Implementation strategy

1. **MVP** = Phases 1–3 (panel + words-only answers + model) → demo offline answers.
2. + US2 (Markdown) → replies readable; ship-quality for the panel.
3. + US3 mechanism (T036–T043) on one group (T045 basics) → demo Show me.
4. + remaining anchor groups (T044, T046–T054) → FR-020 complete; companion nota-docs PR.
5. + US4 and polish → PR with screenshots (nota-pr skill).
