# Tempo contract

C ABI: POD point (beat, BPM, shape and four handles), map get/set, BPM at beat,
beat-to-seconds and inverse. Validate the complete replacement before publishing.
Zero count removes automation. Checkpoint selects normal or preview publication.
Managed port exposes value data only. Selection is transient UI state.

Each gesture commits once. No-op and cancellation create no history entry.
Ctrl+Alt omits the ending marker while retaining the previous-anchor adjustment.
